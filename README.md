# Pokédex Hoenn — ROSA

Application web/PWA de suivi du Pokédex régional Hoenn de Pokémon Rubis Oméga / Saphir Alpha.

## Contenu
- 211 entrées dans l'ordre du Pokédex Hoenn ROSA
- progression 0–211
- distinction des 208 Pokémon requis pour la complétion régionale
- obtenu / en cours / impossible / manquant
- favoris/épingles
- recherche et filtres
- fiche détaillée
- évolution
- types
- œuf
- sprites normaux et shiny
- sauvegarde locale
- export/import JSON
- thème clair/sombre
- PWA installable

## Publication GitHub Pages
1. Crée un dépôt GitHub, par exemple `Pokedex-Hoenn`.
2. Envoie **tout le contenu de ce dossier** à la racine du dépôt.
3. Dans GitHub : Settings → Pages.
4. Source : Deploy from a branch.
5. Branche : `main`, dossier `/root`.
6. Enregistre puis attends la publication.
7. Ouvre l'URL Pages sur Android avec Chrome.
8. Menu Chrome → Ajouter à l'écran d'accueil / Installer l'application.

## Important
Les sprites sont chargés depuis PokeAPI. Une connexion est donc nécessaire au premier affichage des sprites. La progression, les réglages et l'interface sont conservés localement.

La documentation de référence confirme que le Pokédex Hoenn ROSA contient 211 entrées et que Rayquaza, Jirachi et Deoxys ne sont pas requis pour atteindre la complétion régionale de 208 Pokémon.


## Sources de vérification des lieux
- Serebii, Hoenn Pokédex OR/AS : https://www.serebii.net/omegarubyalphasapphire/hoenndex.shtml
- Pokémon Database, Pokédex OR/AS : https://pokemondb.net/pokedex/game/omega-ruby-alpha-sapphire
